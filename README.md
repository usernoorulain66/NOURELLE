NOURELLE — Elegance That Shines

About the Project:

NOURELLE is a responsive fashion website created as a final web development internship project. It helps users explore different outfits in a simple and attractive way.

Technologies Used:

1. HTML
2. CSS
3. JavaScript
4. Git and GitHub

Product Categories

The website includes five categories:

1. Party Wear
2. Casual Wear
3. Fancy Wear
4. Winter Collection
5. Co-ord Sets

Features:

1. Responsive website design
2. Product search
3. Category filtering
4. Add to Cart button and cart count
5. Product details popup
6. Contact form validation

Project Files:

1. "index.html" — Website structure
2. "style.css" — Website design and layout
3. "script.js" — Interactive features
4. "images/" — Product images
